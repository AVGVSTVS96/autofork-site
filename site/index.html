Set it up once.

  1. 1

    Fork it

    Fork the repo on GitHub and clone it, like any fork.

  2. 2

    Run init

    It adds the nightly workflow. --verify takes the command that tests a build.

    npx github:AVGVSTVS96/autopatch init owner/repo --verify "bun test"
  3. 3

    Add a token and push

    Save what this prints as the CLAUDE_CODE_OAUTH_TOKEN secret. That's it.

    claude setup-token

Change anything. Say why.

Edit the code however you like, by hand or with your agent. Then add saves it as a patch: your words and your diff.

$ autopatch add window-title "The window title shows the thread you're looking at, so several T3 Code windows are easy to tell apart."

  • No code yet? add just the words, and the agent writes it on the next sync.

Every night, it rebuilds your fork.

Upstream's newest commit that passed its checks Your patches, applied with git Any that no longer fit, redone by an agent from their PATCH.md Any that upstream now does itself, dropped Your tests, then a signed commit

No agent runs when every patch fits. If anything fails, nothing is pushed.

Four commands.

init owner/repo
Track upstream from your fork. Writes the workflow and .autopatch/config.json.
add id "what and why"
Turn your changes into a patch, or fold them into one.
status
List your patches, and any changes no patch holds yet.
sync
What the action runs every night. Run it yourself any time.

Run with npx github:AVGVSTVS96/autopatch. Uses Claude Code; set agent in config.json for Codex or another CLI agent.
