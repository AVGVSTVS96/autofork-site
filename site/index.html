Intent

The window (and browser tab) title shows the thread you're looking at, as <thread title> · <project name>, or just the thread title when there's no project. With several T3 Code windows open, the dock, window switcher and tab bar can tell them apart instead of all reading "T3 Code".

Invariants

  • Upstream's app title logic (DocumentTitleSync) stays as it is.
  • Renaming a thread updates the title right away.

on:
  schedule:
    - cron: "17 6 * * *"
  workflow_dispatch:

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with:
          fetch-depth: 0
          persist-credentials: false
      - uses: pnpm/action-setup@v6
      - uses: actions/setup-node@v7
        with:
          node-version: 24
      - uses: AVGVSTVS96/autopatch@v1
        env:
          CLAUDE_CODE_OAUTH_TOKEN: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}
